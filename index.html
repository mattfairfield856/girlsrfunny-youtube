Girls R Funny Publisher

Girls R Funny Publisher is a small private tool run by the Girls R Funny YouTube channel (@GirlsRFunny). The channel is a comedy parody channel of vertical Shorts performed by AI-generated performers, labelled as synthetic content. The tool lets the channel owner upload the channel's own finished videos to the channel's own YouTube account, with a title, description, visibility setting and a synthetic-content disclosure chosen by the owner.

It has one user: the channel owner. It does not read other people's data, does not act for anyone else and has no public sign-up. It uses YouTube API Services.
